Understand the system

Three access domains

FDMA separates simultaneous carriers in frequency and uses guard bands. TDMA separates bursts in time and requires timing, synchronization and guard intervals. CDMA distinguishes overlapping transmissions using codes and correlation; code separation does not eliminate multiuser interference or power-control requirements. The aim is efficient use of limited power and spectrum.

Source: week 3/reference.pdf · PDF page 289

Common mistakes

  • Bits are not bytes.
  • Capacity counts must be floored, not rounded upward.
  • State whether reference burst guards are included.
  • FDMA nonlinear multicarrier amplification may need backoff.

Counts: integers; b: bits; R_T: bit/s; T_f: s

Lecture convention includes reference guards.

Example: For 10000 frame bits, 2 reference bursts of 100 bits, 3 traffic preambles of 50 bits and 10-bit guards, lecture overhead = 200 + 150 + 50 = 400 bits; efficiency = 96%.

Worked approach

FDMA

Single channel per carrier assigns one baseband channel to an RF carrier. The simple bandwidth-limited ceiling is floor(transponder bandwidth / channel spacing), assuming spacing already includes guard allowance and power is sufficient. The final’s 54 MHz / 60 kHz gives 900 channels.
