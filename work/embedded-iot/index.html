Developed a wearable muscle activity monitoring system using the MyoWare 2.0 EMG sensor and a custom Flutter mobile application for real-time visualization and analysis. Surface electrodes capture muscle signals, which stream to the app as live graphs and metrics including peak values, mean amplitude, and signal variability. Firebase provides real-time data synchronization and cloud storage.
