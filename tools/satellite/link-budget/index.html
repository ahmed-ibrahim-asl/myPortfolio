Understand the system

Carrier ledger

At each receive plane, add transmit EIRP and receive gain, then subtract free-space and additional losses. Noise uses the equivalent system temperature at that same plane. Atmospheric absorption reduces carrier and thermal emission can contribute antenna noise; path loss and path noise are different mechanisms.

CdBW=EIRPdBW−Lpath,dB+Gr,dBi−Lother,dBC_{dBW}=EIRP_{dBW}-L_{path,dB}+G_{r,dBi}-L_{other,dB}CdBW​=EIRPdBW​−Lpath,dB​+Gr,dBi​−Lother,dB​

C: carrier power; L: positive dB losses.

Every term must belong to the same link direction and reference plane.

Common mistakes

  • Never add C/N values directly in dB.
  • Do not subtract bandwidth twice.
  • Use matching noise reference planes and common bandwidths for composite ratios.

Worked approach

EIRP and path loss

C/N₀ in dB-Hz uses receive G/T and the logarithm of Boltzmann’s constant. Subtract 10 log bandwidth to obtain C/N; subtract 10 log bit rate to obtain Eb/N₀. A symbol rate is not a bit rate unless modulation and coding justify that conversion.

Questions engineers ask

Which topics does Satellite Link Budget Calculator cover?

EIRP and path loss; C/N0; C/N; Eb/N0; FT composite links; Margin; Path noise.

How should I check my work in Satellite Link Budget Calculator?

Read the stated assumptions and source references, check units and independently repeat a worked example before relying on the result.

Does Satellite Link Budget Calculator operate real satellite equipment?

No. This is a browser-based educational resource. It does not transmit RF signals, command spacecraft or certify a working link.
